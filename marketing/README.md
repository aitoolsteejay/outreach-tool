# Marketing

`landing.html` is the standalone sales/marketing page for Myntmore Outreach. It's a self-contained
static HTML file (no build step, no dependency on the Next.js app) — open it directly in a browser
to preview it.

It's also published as a Claude Artifact for easy sharing/editing:
https://claude.ai/code/artifact/2046d07e-4653-4814-86ed-c353cdff9f77

The CTAs on the page point to `mailto:hello@myntmore.com` as placeholders — swap in the real sales
inbox before sending this out, and update both this file and the artifact together so they stay in sync.
